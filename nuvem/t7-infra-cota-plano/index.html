Cota real do plano

Uma barra de status para o Claude Code no Windows que mostra a cota de 5 horas e de 7 dias e grava uma linha por minuto em ~/.claude/cota.jsonl. Junto vem um relatorio.py que diz o consumo por dia e por hora e avisa se a cota semanal passar de 80% antes de quarta. Há duas versões da barra, Node e Git Bash, com saída idêntica e sem dependência nova.

Essas duas linhas são a saída dos testes: o JSON de exemplo da documentação e uma variação dele. Verde fica abaixo de 50%, amarelo vai de 50% a 79% e vermelho começa em 80%. Se você já usa uma barra, ponha o comando dela em ~/.claude/cota-base.txt: ela continua aparecendo e a cota vem depois.

O que a documentação diz

Conferido em 14/10/2026 em code.claude.com/docs/en/statusline:

  • Os nomes exatos: rate_limits.five_hour.used_percentage e rate_limits.seven_day.used_percentage, de 0 a 100, e rate_limits.five_hour.resets_at e rate_limits.seven_day.resets_at, em segundos Unix.
  • rate_limits só vem para assinante Pro ou Max (ou atrás de um gateway com limite de gasto) e só depois da primeira resposta da sessão. Cada janela pode faltar, e some quando passa o reset dela.
  • A barra roda a cada evento (com debounce de 300 ms), no reset de uma janela e a cada refreshInterval segundos. Com 60, ela grava também com a sessão parada.
  • No Windows o comando roda pelo Git Bash quando ele existe e pelo PowerShell quando não. O caminho tem de usar barra normal.

No claude -p: a página da barra não fala do -p, e o -p não tem a interface onde a barra vive, então o script não deve rodar lá. Não verifiquei rodando. Os números chegam por outros caminhos:

  • No --output-format stream-json vem o evento rate_limit_event, com status, resetsAt e utilization de 0 a 1 (não de 0 a 100). O SDK em Python também lê o tipo da janela. Pela documentação, ele sai quando a sessão encontra um limite ou quando o status muda (por exemplo, de allowed para allowed_warning). Está em agent-sdk/typescript e agent-sdk/python.
  • O /usage mandado como prompt devolve usage_report.rate_limits.limits, com percent de 0 a 100 e resets_at em ISO. A documentação marca esse formato como experimental.

Para instalar no PC

1. copie statusline-cota.mjs (ou .sh) e relatorio.py para C:/Users/loren/.claude/
2. se já tem barra, copie o "command" dela para C:/Users/loren/.claude/cota-base.txt
3. em C:/Users/loren/.claude/settings.json:
   "statusLine": { "type": "command", "command": "node ~/.claude/statusline-cota.mjs", "refreshInterval": 60 }
   (sem Node: "command": "bash ~/.claude/statusline-cota.sh")
4. abra o Claude Code e mande uma mensagem; o 5h e o 7d aparecem depois da primeira resposta
5. python C:/Users/loren/.claude/relatorio.py --saida C:/Users/loren/.claude/cota.md

Como o relatório conta

  • Consumo: a diferença entre duas amostras seguidas da mesma janela, em pontos percentuais. Quando a janela vira, o percentual novo foi gasto depois do reset e conta inteiro.
  • Alerta de quarta: a semana atual vai de resets_at menos 7 dias até resets_at. Se alguma amostra passou de 80% antes da primeira quarta 00:00 dessa semana, sai um alerta. O limite e o dia mudam com --limite e --dia.
  • Ritmo: usa os pontos por hora nas últimas 24 h, com pelo menos 3 h de registro. Ele avisa se a cota vai chegar a 80% antes de quarta ou acabar antes do reset.
  • Várias sessões abertas gravam no mesmo arquivo. A trava deixa passar uma linha por minuto, e o relatório junta o que cair no mesmo minuto.

Limitações e o que não deu para verificar

  • Testado no Linux da nuvem (bash 5.2, Node 22), não no Windows. O .sh precisa de bash 5, que o Git Bash atual tem. Se a hora sair errada, use o .mjs.
  • Não verificado: o comportamento real no claude -p e se o Claude Code no Windows passa o fuso certo para o script.
  • Com o Claude Code fechado não há amostra. O que foi gasto nesse tempo, inclusive no claude.ai, no app e nas sessões na nuvem, que dividem a mesma cota, aparece de uma vez na amostra seguinte. O que foi gasto entre a última amostra e um reset se perde.
  • O arquivo cresce até uns 290 KB por dia e não tem rotação.
