Cadastro do Banco Central

A base é a de Dados cadastrais de entidades supervisionadas (Olinda, BcBase v2), atualizada todo dia a partir do Unicad:

https://olinda.bcb.gov.br/olinda/servico/BcBase/versao/v2/odata/EntidadesSupervisionadas?$top=5&$format=json
https://olinda.bcb.gov.br/olinda/servico/BcBase/versao/v2/odata/$metadata

O cadastro não tem histórico de eventos. Por isso, vigia_bc.py guarda um retrato por dia e compara com o anterior: quem entrou, quem saiu e o que mudou (situação, tipo, nome). Com --so-cambio-pagamentos, ficam só câmbio, instituição de pagamento, ativos virtuais e crédito direto. O passo a passo e os alertas que importam para a Ozav estão no cadastro_bc.md.

pip install pandas requests
python vigia_bc.py esquema
python vigia_bc.py baixar          # todo dia
python vigia_bc.py diff --so-cambio-pagamentos

Exemplo real de hoje: não foi possível. olinda.bcb.gov.br está bloqueado nesta sessão, então não há retrato nem contagem reais, e nenhum foi inventado. Os endereços são os documentados no portal de dados abertos, segundo o buscador; os nomes de campo não foram verificados, e o script os lê do $metadata.

Limitações e o que não deu para verificar

  • Bloqueado nesta sessão (HTTP 403 no proxy de saída; a ferramenta de leitura de páginas também não alcança esses domínios): os sites de todas as empresas, olinda.bcb.gov.br e dadosabertos.bcb.gov.br. Nenhuma página foi aberta.
  • Cada URL do CSV apareceu nos resultados de busca; o que não apareceu ficou em branco. Frases, datas e números vêm dos resumos da busca e estão marcados “não verificado” quando a busca não confirmou.
  • A pesquisa foi dividida entre três agentes, e a cota de buscas acabou antes de alguns bancos e plataformas. Uma busca complementar confirmou Inter e C6. BTG, Itaú, Banco do Brasil, Daycoval, Currencycloud e Deel seguem “a verificar”.
  • A coluna concorrencia_com_ozav é uma classificação desta análise, feita a partir do que cada linha diz: alta (atende PJ brasileira com câmbio), média (adjacente) e baixa (não atende PJ no Brasil ou saiu do mercado).
  • Plataformas que operam por meio de um parceiro autorizado não aparecem com CNPJ próprio no cadastro do BC. Para elas, a vigia é pelo site.
